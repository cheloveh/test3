# 🚀 TechZone — Интернет-магазин электроники

Современный интернет-магазин электроники с AI-ассистентом, системой аккаунтов и SQL базой данных.

![TechZone](https://img.shields.io/badge/React-18-blue) ![TypeScript](https://img.shields.io/badge/TypeScript-5-blue) ![Tailwind](https://img.shields.io/badge/Tailwind-3-purple)

## ✨ Особенности

- 🛒 **150+ товаров** с реальными ценами и характеристиками
- 🗄️ **SQLite база данных** (sql.js) — работает прямо в браузере
- 👤 **Система аккаунтов** — регистрация, авторизация, профиль
- 🤖 **AI-ассистент** — помощь в выборе товаров
- 🔍 **Умный поиск** и фильтры по категориям, брендам, ценам
- 📱 **Адаптивный дизайн** — идеально работает на всех устройствах
- ⚡ **Быстрый SPA** — мгновенная навигация без перезагрузок

## 🚀 Деплой на GitHub Pages

### Автоматический деплой (рекомендуется)

1. **Создайте репозиторий на GitHub**
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO_NAME.git
   git push -u origin main
   ```

2. **Включите GitHub Pages**
   - Перейдите в Settings → Pages
   - Source: **GitHub Actions**
   - Сохраните

3. **Готово!** При каждом пуше в `main` сайт будет автоматически деплоиться
   - URL: `https://USERNAME.github.io/REPO_NAME/`

### Ручной деплой

```bash
# Установите зависимости
npm install

# Соберите проект
npm run build

# Задеплойте папку dist/ на GitHub Pages
# (используйте gh-pages или другой инструмент)
```

## 🛠️ Локальная разработка

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр продакшен-сборки
```

## 🗄️ База данных

Проект использует **SQLite через sql.js** — полноценная SQL база данных, работающая прямо в браузере:

- Данные сохраняются в `localStorage`
- Таблицы: `users`, `orders`, `order_items`, `cart`, `favorites`, `reviews`
- Поддержка транзакций и foreign keys
- Мгновенные запросы без сервера
